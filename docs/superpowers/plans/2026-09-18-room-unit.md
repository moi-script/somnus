# Room Unit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring the XIAO ESP32-C6 radar + Tuya bulb into Somnus as a WiFi device, analyse each night's presence and light, and show it in a new Sleep tab with light controls.

**Architecture:** New `presence` / `light` frames and `light` / `auto` commands in `@lacs/contracts`; a pure `summarizeNight()` there too. The API stores room frames in their own collection through the existing `/ingest`, serves night summaries, and reuses the device-token command queue. The web app gains a Sleep tab; the C6 firmware posts frames and drains commands over HTTP.

**Tech Stack:** TypeScript, zod, vitest, Express, Mongoose, Next.js 15 + Tailwind, Arduino (esp32 core 3.3.7, ArduinoJson 7).

**Spec:** `docs/superpowers/specs/2026-09-18-room-unit-design.md`

## Global Constraints

- UI copy says "in the room", never "in bed" or "asleep". Light facts, no scores.
- Absence < 2 min = noise (bridged). 2–60 min = room emptied (counted). ≥ 60 min splits stretches. Stretch opens on a presence run ≥ 20 min. < 60 min presence in window → not recorded.
- Night window 18:00 → 14:00 next day, local time, labelled by the evening's date.
- Presence heartbeat 60 s; a sample older than 90 s is `unknown`, never interpolated.
- Device ids: `lacs-xxxxxx` band, `room-xxxxxx` room unit (6 lowercase hex).
- Existing tests must stay green: contracts 20, API 27.

## Deviations from the spec (decided while reading the code)

1. **Device kind is derived from the id prefix** (`deviceKindOf(id)`), not stored. Same effect, no migration for devices already claimed.
2. **The client sends its UTC offset** (`?tz=` minutes, as `Date.getTimezoneOffset()`), so the server never guesses the local time zone.
3. **`useDevice` separates bands from the room unit.** `active` is only ever a band; `room` is the first room unit. Without this, claiming a room unit could make the Health tab read a radar.
4. **Added `GET /devices/:id/room/latest`** so the live card has a state before the first SSE frame.
5. **The room unit also emits `ack` frames** so the app sees command results live, alongside the existing ack route.

**Produces:**
```ts
export const NIGHT = { noiseMs: 120_000, splitMs: 3_600_000, openRunMs: 1_200_000,
  minRecordedMs: 3_600_000, staleMs: 90_000 } as const;
export type LightGroup = 'off'|'warm'|'neutral'|'cool'|'red_amber'|'green'|'blue_violet'|'other'|'unknown';
export interface PresenceSample { at: number; present: boolean }
export interface LightSample { at: number; state: LightState; source: LightSource }
export interface NightWindow { start: number; end: number }
export function nightWindow(date: string, tzOffsetMin: number): NightWindow;
export function nightDateFor(at: number, tzOffsetMin: number): string;   // which night a moment belongs to
export function lightGroup(s: LightState | null): LightGroup;
export function lightCss(s: LightState | null): string | null;           // real bulb colour, null when off/unknown
export interface NightSummary {
  date: string; recorded: boolean; window: NightWindow;
  stretch: { start: number; end: number } | null;
  inRoomMs: number; emptiedCount: number; longestStretchMs: number; coverage: number;
  presence: Array<{ from: number; to: number; state: 'present'|'absent'|'unknown' }>;
  light: {
    timeline: Array<{ from: number; to: number; group: LightGroup; css: string | null; bright: number | null }>;
    groupMs: Record<LightGroup, number>;
    changes: { total: number; bySource: Record<LightSource, number> };
    consistency: { group: LightGroup; share: number } | null;
    onWhilePresentMs: number; avgBrightness: number | null; coolOrBlueMs: number;
  };
}
export function summarizeNight(date: string, window: NightWindow,
  presence: PresenceSample[], light: LightSample[]): NightSummary;
```

Algorithm: presence samples (sorted) become intervals; each sample's state holds until the next sample or `at + staleMs`, whichever is first, after which `unknown`. Non-present gaps: total < noiseMs → bridged; known-absent ≥ noiseMs and total < splitMs → emptied; total ≥ splitMs → split. A stretch opens at the first present run ≥ openRunMs. Main stretch = longest; < minRecordedMs present time in window → `recorded:false`. Light: step function from samples (state before first in-window sample = the last earlier sample passed in, else unknown), clipped to the stretch. Changes = in-stretch samples whose state differs from the previous state.
